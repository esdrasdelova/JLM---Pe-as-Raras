# JLM - Loja de Roupas Masculinas

Loja virtual de moda masculina desenvolvida com C# e ASP.NET Core MVC.

## Tecnologias
- C#
- ASP.NET Core MVC
- Entity Framework Core
- MySQL

## Funcionalidades
- Catálogo de roupas e acessórios masculinos
- Carrinho de compras
- Cadastro e login
- Painel administrativo
